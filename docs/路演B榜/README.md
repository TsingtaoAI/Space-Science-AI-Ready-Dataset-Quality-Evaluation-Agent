
每个 tar 包解包后是一个数据目录，目录名与 tar 包名一致（去掉 `.tar`）。

## 三步开始

**第一步：校验**

```bash
cd OPC_Roadshow_B_20261105
sha256sum -c SHA256SUMS.txt
```

全部显示 `OK` 才继续。出现 `FAILED` 说明传输过程中内容有变，请重新获取该数据包。

**第二步：解包**

```bash
mkdir -p 数据目录
for f in 数据/*.tar; do
  tar -xf "$f" -C 数据目录/
done
ls 数据目录 | wc -l      # 应为 12
```

解包后需预留 50 GiB 可用空间。如遇权限问题，`chmod -R u+rw 数据目录` 即可。

**第三步：读要求**

先读 `01_现场展示数据清单.md`，它给出本轮的数据范围与字段读取方式；再读 `02_选手展示和自测要求.md`，它给出自测须完成的内容、结论的组织方式与提交格式。两份均为必读。

## 本包与完整 B 榜包的关系

完整 B 榜包共 6 个数据集、24 个数据目录，本包发放其中 3 个数据集的全部 4 个目录，共 12 个目录，其余 12 个目录不发放、不参与本轮展示。

此前随完整 B 榜包下发的说明文档，其数据集个数、目录个数与文件数量与本包不同，属正常情形；本轮的范围与字段以 `01_现场展示数据清单.md` 为准，要求以 `02_选手展示和自测要求.md` 为准。本包不含说明文档。

## 数据概况

| 数据集 | 数据形态 | 标注形态 | 目录数 |
| --- | --- | --- | ---: |
| AIA_AR_sample | 4096 × 4096 PNG 太阳极紫外图像 | 事件多边形框 + 物理量 | 4 |

## 注意事项

1. **不要修改 `数据/` 下的任何文件**。数据目录内的文件须与发放时逐字节一致。
2. **目录名末尾的 10 位随机后缀与内容无关**，不要试图从名字推断内容。
3. **同一数据集的 4 个目录，对象互不重叠**。可以把两个目录的统计特征拿来比较，但不存在同一文件两份可供逐字节对齐。
4. 所有 tar 包内的文件时间戳已统一，权限为源端原样。
5. 数据包内的 PNG 与 CSV 本身已压缩或为纯文本，二次压缩收益有限，故本包以存储方式打包，体积与解包后大致相当。

## 环境建议

- Linux 或 macOS 原生 `tar`，Windows 10 及以上自带 `tar.exe`
- Python 3.8 及以上，`numpy`、`Pillow` 可覆盖绝大部分统计
- 处理数万个小文件时，注意文件句柄上限（`ulimit -n 65536`）
- 解包与遍历建议使用固态盘，机械盘的耗时约为固态盘的十倍以上
