## 一、适用范围

本清单规定闭门路演现场展示所使用的数据范围。现场展示使用 **3 个数据集，每个数据集 4 个数据目录，共 12 个目录**。

同一批数据同时用于赛前自测。参赛队在赛前完成全部目录的评价，自测结论即为现场陈述的对象，两处使用同一批数据与同一套校验和，不在现场重新发放。

完整 B 榜包共 6 个数据集、24 个数据目录。本轮发放其中 3 个数据集的全部四个目录，其余 12 个目录不发放、不参与展示。

本轮发放范围与校验和以本清单为准。

## 三、包内结构与配对规则

每个数据包解包后得到同名目录，目录名与数据包名一致（去掉 `.tar`）。

### 3.1 三种目录布局

| 布局 | 数据集 | 结构 |
| --- | --- | --- |
| 两级 | AIA_AR_sample | `data/` 存图像，`label/` 存标注 |
| 扁平（图像） | EPB_seg_sample | 图像与标注同目录 |
| 扁平（时序） | ULF_sample | CSV 与标注同目录 |

### 3.2 配对规则

| 布局 | 数据文件 | 标注文件 | 配对方式 |
| --- | --- | --- | --- |
| 两级 | `data/X.png` | `label/X.png.json` | 标注文件名 = 数据文件名 + `.json` |
| 扁平（图像） | `X.png` | `X.json` | 标注文件名 = 数据文件名主干 + `.json` |
| 扁平（时序） | `X.csv` | `X.csv.json` | 标注文件名 = 数据文件名 + `.json` |

**两级布局的标注文件扩展名为 `.png.json`，不是 `.json`。** 按 `.json` 后缀检索 `label/` 目录将得到空集。

文件名一律为 20 字符随机串，字符集 `[0-9a-zA-Z_]`，不含原始名称、设备或时间信息。数据文件与标注文件各自独立命名，文件名之间没有可推导的对应关系之外的信息，配对只能依据文件名本身。

### 3.3 数量统计

```bash
# 两级布局
ls 数据/AIA_AR_sample_z4h764sf2d/data/*.png    | wc -l
ls 数据/AIA_AR_sample_z4h764sf2d/label/*.json  | wc -l

# 扁平布局
ls 数据/EPB_seg_sample_qmn05l7r91/*.png        | wc -l
ls 数据/EPB_seg_sample_qmn05l7r91/*.json       | wc -l

# 时序布局
ls 数据/ULF_sample_09b7y3z4hn/*.csv            | wc -l
ls 数据/ULF_sample_0yu0mc7d5a/*.csv.json       | wc -l
```

命令中的目录名与文件名均须替换为实际值。解包结果与该命令的输出是否一致，可作为环境与脚本的入口校验。

## 四、字段读取规则

三个数据集的字段位置不一致，按数据集分别读取。

### 4.1 标注来源与基础信息

全部标注文件的顶层为 `label_header`、`basic_annotation`、`science_annotation` 三个容器，其内容随数据集而异。

| 字段 | AIA_AR_sample | EPB_seg_sample | ULF_sample |
| --- | --- | --- | --- |
| 标注生成时间 | `label_header.labelCreateTime` | `label_header.labelCreatTime` | `label_header.labelCreateTime` |
| 标注者 | `label_header.annotator` | `label_header.annotator` | `label_header.annotator` |
| 标注记录编号 | 缺省 | 缺省 | `label_header.identifier` |
| 对应数据文件名 | `basic_annotation.fileName` | 同左 | 同左 |

字段缺失时按缺省处理，不要默认按空串填充后参与判定。

### 4.2 标注目标所在位置

| 数据集 | 目标数组路径 | 图形类型 | 类别字段 |
| --- | --- | --- | --- |
| AIA_AR_sample | `hek_event_annotation.matched_events` | 五点闭合多边形 `bbox_polygon_pixel` | 元素内 `concept` |
| EPB_seg_sample | `science_annotation.mask.shapes` | 多边形 `polygon` | 元素内 `label` |
| ULF_sample | `ulf_event_annotation.matched_events` | **无坐标图形** | 元素内 `kind` |

**类别字段不在同一层级，图形类型亦不同。** AIA 的多边形为五点闭合，首尾点重合；EPB 的多边形为闭合点列，点数不固定；ULF 的事件只有时间区间，不含任何坐标。

AIA 的标注文件中，部分事件的 `bbox_polygon_pixel` 为空数组，此类事件只有物理参数而无坐标框。

### 4.3 图像尺寸字段

| 数据集 | 尺寸记录位置 | 形式 | 实际图像尺寸 |
| --- | --- | --- | --- |
| AIA_AR_sample | 无尺寸字段 | — | 4096 × 4096 |
| EPB_seg_sample | `basic_annotation.imgSize` | 字符串，如 `"1024x1024 pixels"` | 1024 × 1024 |
| ULF_sample | 不适用 | 纯文本时序，无图像 | — |

AIA 不在标注中记录图像尺寸，尺寸须由 PNG 文件头读取。ULF 的数据体为 CSV 文本，不含图像。

### 4.4 时序数据的时间基准

ULF 的 CSV 首列为 `t`，取值为**自观测起始时刻起的秒偏移**（0、1、2……），不是绝对时刻。

绝对时刻由 `basic_annotation.startTime` 与 `t` 相加得到。标注内事件的 `start_dt`、`end_dt` 为绝对时刻，与 CSV 的 `t` 列不在同一坐标系，比较时须先换算。

CSV 列名为 `t,H,D,Z,T`，其中 `D` 为磁偏角，单位为度；其余三分量为磁场强度，单位为纳特斯拉。

### 5.2 解包

```bash
mkdir -p 数据目录
for f in 数据/*.tar; do
  tar -xf "$f" -C 数据目录/
done
ls 数据目录 | wc -l          # 应为 12
```

解包后如遇权限问题，`chmod -R u+rw 数据目录` 即可。

### 5.3 遍历规模

12 个目录合计约 4.9 万个文件，其中 ULF 四个目录占 2.8 万个，AIA 四个目录占 1.5 万个。ULF 的文件数量多但单文件体积小，AIA 相反。遍历前请确认文件句柄上限：

```bash
ulimit -n 65536
```

## 附、名词解释

| 术语 | 解释 |
| --- | --- |
| 数据集 | 一批同源观测对象及其标注的集合，以 `datasetId` 标识。本轮发放三个：`AIA_AR_sample`、`EPB_seg_sample`、`ULF_sample` |
| 目录 | 数据集内一次加工形成的完整数据与标注集合，以 `dirId` 标识。目录名由数据集名加 10 字符随机串构成 |
| 数据包 | 一个目录经 tar 打包后的文件，包名与解包后的目录名相同 |
| 对象 | 一个数据文件及其对应标注构成的单位。图像类为一张图，时序类为一个时段 |
| 标注文件 | 记录对象标注内容的 JSON 文件，与数据文件一一对应 |
| 标注目标 | 标注文件内记录的一个待检实体。图像类为一个多边形框或掩膜，时序类为一个时间区间 |
| 两级布局 | 图像与标注分目录存放的结构，`data/` 存图像，`label/` 存标注 |
| 扁平布局 | 数据文件与标注文件同目录存放的结构，含扁平（图像）与扁平（时序）两种 |
| 配对 | 使数据文件与标注文件建立一一对应关系的过程 |
| 多边形框 | 以若干顶点坐标围成的闭合区域，用于标出图像中目标的边界。AIA 的框为五点闭合，首尾点重合 |
| 掩膜 | 以闭合多边形标出的区域，一个标注文件可含多个掩膜 |
| 时序数据 | 按等间隔时刻排列的数值序列。ULF 的数据体为 CSV 文本，一个文件对应一个 3600 秒的观测时段 |
| 秒偏移 | 相对观测起始时刻的秒数，取值 0、1、2……，不是绝对时刻 |
| PNG 文件头 | PNG 文件开头的固定长度元数据段，记录图像宽高等信息，可在不解码整幅图像的情况下读出尺寸 |
| 解包 | 将 tar 文件展开为目录的过程 |
| 文件句柄 | 进程可同时打开的文件数量配额，由 `ulimit -n` 控制。遍历数万个小文件时可能触及上限 |
| GiB | 以 1024 为进位的容量单位，1 GiB 等于 1024³ 字节，区别于以 1000 为进位的 GB |
| SHA-256 | 一种摘要算法，对文件内容算得 256 位定长值。内容有任一字节差异，摘要即不同，用于校验文件完整性 |
