## 录屏前准备

生成合成 CME 演示数据集：

```bash
python3 tools/make_demo_dataset.py demo_data --cme
```

单独运行这一个数据集：

```bash
docker run --rm --network none -v $(pwd)/demo_data/CME_C2_demo:/data:ro -v $(pwd)/out-cme:/output sqa-agent:0.8.0
```

生成抽查页：

```bash
python3 tools/show_evidence.py out-cme demo_data B05-CME_C2_demo-000001 --out 抽查-B05.html
```

单独挂载一个数据集时，`show_evidence.py` 的第二个参数是数据集的上一级目录（`demo_data`）。

## 注意

- 画面里**只展示合成演示数据**。公开集的数字（273 / 887 / …、检出占比）是统计结果，可以展示；不要在视频里打开比赛样本的图像或标签（保密承诺）。
- 结论编号由运行确定：同一份演示数据重跑，编号与本脚本一致（`B05-CME_C2_demo-000001`、`C05-CME_C2_demo-000001`、`P04-CME_C2_demo-000001/000002`）。
- 旁白里「和上一版相同」指公开集多版本全量运行：0.8.0 与 0.7.2 的档位对照与全局排序完全相同，「不通过」「待判定」「通过」的条数相同，只多了新检查在有同源版本时的 90 条「不适用」记录。
