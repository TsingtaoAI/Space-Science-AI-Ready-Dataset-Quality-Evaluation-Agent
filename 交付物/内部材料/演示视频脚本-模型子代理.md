# 演示视频脚本 · 模型子代理（约 3 分 30 秒）

讲清三件事：模型用在哪里、怎么防止模型出错进入结论、为什么默认关闭。
录屏全部使用**合成演示数据集**（`tools/make_demo_dataset.py` 生成，不含比赛数据），可以接 DeepSeek 等外部模型服务。

## 录屏前准备

生成合成演示数据集（不含比赛数据）：

```bash
python3 tools/make_demo_dataset.py demo_data
```

不开模型运行一次：

```bash
docker run --rm --network none -v $(pwd)/demo_data:/data:ro -v $(pwd)/out-demo:/output sqa-agent:0.8.0
```

开模型运行一次（以 DeepSeek 为例；密钥提前在终端里设置，录屏时不要显示）：

```bash
docker run --rm -e LLM_BASE_URL=https://api.deepseek.com -e LLM_API_KEY -e LLM_MODEL=deepseek-chat -v $(pwd)/demo_data:/data:ro -v $(pwd)/out-demo-llm:/output sqa-agent:0.8.0 run --input /data --output /output --use-llm
```

## 注意

- **只用合成演示数据集**接外部模型。比赛数据受保密承诺约束，不得发给 DeepSeek 等外部服务。
- 真实模型的抽取结果可能和本脚本略有出入（例如没抽到时段声明，或两次不一致落「待判定」）。录之前先跑一遍确认画面内容，旁白按实际结果调整，**不要用模拟服务的结果冒充真实模型**。
- 开关模型前后，评分卡的综合分与维度分完全相同（演示数据集实测均为 98.33）：D04 的结论进入问题清单、检查覆盖与入库结论，但不参与任何程度指标与评分。
