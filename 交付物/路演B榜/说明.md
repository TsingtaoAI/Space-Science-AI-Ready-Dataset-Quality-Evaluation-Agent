## 二、分数口径

- 缺陷密度 d = 至少有一条**计分轨**「不通过」的样本数 / 样本数（样本数 = 标注文件数）
- totalScore = 100 × (1 − d)，保留一位小数；只有标注质量类与文件配对类（附件一计分轨）进入分数，诊断信息、反印证、数据质量三类只列在证据表中
- 分数与缺陷密度严格单调；d 是比例，与目录规模无关，所以三个数据集直接放在一起排全局名次，不是集内排序拼接
- 名次按 d 从小到大；d 相同时依次比较计分轨不通过条数 / 样本数、综合分、目录名，保证不并列
- 结果表 evidence 列中的「N 处」按（样本, 事件）去重：同一事件被两项检查报出只计一处；证据表保留每项检查各自的结论

## 三、单数据集判据与可信度

同一数据集的 4 个目录对象互不重叠，智能体按样本名重合度分组后自动不启用版本对照，只用单个目录内部就能判定的判据（物理约束、结构自洽、数据集定位、跨样本一致、元数据与数据体对质）。

公开集逐档单独运行（模拟没有同源版本）的样本级检出率，见 `tools/single_mode_eval.py`：

| 数据集 | 召回率 P1 / P2 / P3 / P4 | 精确率 | clean 计分轨不通过 |
|---|---|---|---|
| AIA | 0.35 / 0.70 / 0.93 / 0.97 | 1.000 | 0 |
| EPB | 0.76 / 0.74 / 0.75 / 0.77 | 1.000 | 0 |
| ULF | 0.88 / 0.93 / 0.95 / 0.98 | 1.000 | 0 |

真值 = 与 clean 档相比，标签被改而数据文件逐字节相同、或数据文件缺失的样本；图像与标注一并做了几何变换的样本属反印证类，不计入真值。真值只用于评估，不进入任何判据。

## 四、判不了的项（标 undetermined）

| 项 | 原因 | 所缺基准 |
|---|---|---|
| EPB 掩膜小幅平移、范围缩放（L2-G、L3-MIS） | 掩膜内外亮度对比试验：干净掩膜有 18% 并不比周围暗，信号不足 | 参考掩膜或经标定的分割模型 |
| AIA 漏标（L3-06） | 漏掉的目标不在标注里 | HEK 事件目录全量 |
| L2-A / L2-B / L2-C / L1-TS | 附件一列为非计分轨，需外部基准 | 源事件目录、原始观测 |
| ULF 的 D 分量超出 ±180 | 声明单位为度，干净目录约三成文件取值达数百，像 nT 或角分 | 台站元数据的单位定义 |
| 使用条件 | 数据包没有许可与用途文件 | 使用权限与用途说明 |

公开集个别注入样本带有标记字段（如 `concept_swapped`、`fabricated`），只用于离线评估，判据中不读取（第八章「不允许使用注入参数」）。
